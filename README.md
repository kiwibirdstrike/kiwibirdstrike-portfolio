# 이주성 Master Portfolio

통계·데이터 분석을 기반으로 업무를 구조화하고, 모델과 AI를 실제 의사결정에 연결해 온 경험을 정리한 마스터 포트폴리오입니다.

## 수정과 확인

분류는 사용 기술이 아니라 프로젝트의 주된 목적과 산출물을 기준으로 하나만 선택합니다.

| 분류 | 기준 | 프로젝트 |
| --- | --- | --- |
| 연구 논문 | 방법론 제안과 논문 | ILR Polygram, GCER |
| 예측·최적화 모델 | 예측 성능 또는 최적 배치안 | 선박 매칭, 제구 성공 확률, 수면 장애 분류, 부스 배치, 체육시설 입지 |
| 데이터 분석·통계 자문 | 데이터 해석과 자문·정책 제안 | 와인, 영어 설문, 화재, 공실, 요양 인력, 뉴스 이용·신뢰 |
| 서비스·도구 개발 | 사용자가 실행하는 서비스·프로그램·패키지 | 공공레이더, TVspline, 제조데이터 분석 도구, 미팅 예약, AutoResearch |
| 팀 운영 | 학습과 협업 운영 | 통계 학습 소모임 |
| 기타 | 별도로 정리한 활동 | WorldQuant |

모델을 사용해도 분석·자문이 중심이면 분석으로, 웹 화면이 있어도 최적 배치안이 중심이면 예측·최적화로 분류합니다. 와인은 설문 응답과 분류 기준을 검토한 자문, 요양 인력은 지역 위험 분석과 정책 제안이 중심입니다. 제조데이터 프로젝트는 분석 결과를 조회하고 설명받는 도구 개발이 중심입니다.

1. `portfolio-content.js`에서 소개, `categories` 분류와 `projects` 내용을 수정합니다. 모든 프로젝트는 하나의 아카이브와 `project.html?id=…` 상세 페이지를 사용합니다.
2. `node scripts/validate.mjs`를 실행합니다.
3. `python3 -m http.server 4173`으로 로컬에서 확인합니다.

GitHub Pages는 `main` 브랜치의 루트 디렉터리를 배포 대상으로 사용합니다.

이 사이트는 별도 정적 사이트입니다. 비공개 커리어 DB를 수정해도 자동 동기화되지 않습니다. 공개할 내용만 선별해 이 저장소에 반영하고 배포해야 합니다.
