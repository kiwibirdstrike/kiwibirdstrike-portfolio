# 이주성 Master Portfolio

통계·데이터 분석을 기반으로 업무를 구조화하고, 모델과 AI를 실제 의사결정에 연결해 온 경험을 정리한 마스터 포트폴리오입니다.

## 수정과 확인

1. `portfolio-content.js`에서 소개와 프로젝트 내용을 수정합니다. 대표 프로젝트와 아카이브 모두 `project.html?id=…` 상세 페이지를 사용합니다.
2. `node scripts/validate.mjs`를 실행합니다.
3. `python3 -m http.server 4173`으로 로컬에서 확인합니다.

GitHub Pages는 `main` 브랜치의 루트 디렉터리를 배포 대상으로 사용합니다.

이 사이트는 별도 정적 사이트입니다. 비공개 커리어 DB를 수정해도 자동 동기화되지 않습니다. 공개할 내용만 선별해 이 저장소에 반영하고 배포해야 합니다.
